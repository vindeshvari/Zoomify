# Zoomify 📹

A full-stack video conferencing web application designed for seamless real-time video calls and interactive online meetings.

---

## 🌟 Key Features

* **Real-Time Video & Audio:** Low-latency peer-to-peer audio and video streaming.
* **Instant Room Creation:** Effortlessly create or join virtual meeting rooms.
* **Responsive Interface:** User-friendly design tailored for both desktop and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript / Frontend Web Framework
* **Backend:** Node.js, Express.js
* **Real-Time WebRTC / WebSockets:** WebRTC, Socket.io
* **Deployment:** Render
